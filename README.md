# Conversor Bitcoin

Aplicativo Android desenvolvido para a atividade de Usabilidade em Dev Web, Mobile e Jogos.

## Funções
- Conversão de Real (BRL) para Bitcoin (BTC)
- Conversão de Bitcoin (BTC) para Real (BRL)
- Cotação fixa: 1 BTC = R$ 600.000,00

## Tecnologias
- Android Studio
- Java
- XML
- Android SDK

## Como usar
Digite um valor e escolha a direção da conversão.
